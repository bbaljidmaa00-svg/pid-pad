# Пид Пад

Найзуудтайгаа цуглахад тоглох тоглоомын сайт. Нэг утсыг дамжуулж, хөзөр шагайгаа гаргаж, эсвэл дүрмийг нь хараад утасгүй тоглоно.

## Файлууд

- `app.html`: сайтын бүх код (засах бол үүнийг засна)
- `index.html`: `./build.sh` ажиллуулахад `app.html`-ээс үүснэ, Cloudflare үүнийг үзүүлнэ
- `custom.json`: бүх хүнд харагдах өөрийн тоглоом, асуулт, шийтгэлүүд

## Өөрийн агуулгаа бүх хүнд харуулах

1. Сайт дээр **Засах** дараад тоглоом нэмэх эсвэл асуулт, шийтгэлээ засна.
2. **Хуваалцах → Хуулах** дарна.
3. GitHub дээр `custom.json`-г нээгээд хуулсан текстээ буулгаж хадгална (Commit).
4. Cloudflare хэдэн секундэд шинэчилнэ.

## Cloudflare Pages-д холбох (нэг удаа)

1. dash.cloudflare.com → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
2. Энэ репог сонгоно.
3. Build command: хоосон. Build output directory: `/`.
4. **Save and Deploy**. `pid-pad.pages.dev` шиг хаяг гарна.
